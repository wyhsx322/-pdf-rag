# RAG-GEN-0001｜基于检索证据的流式回答生成基线

## 需求

- 基于检索证据生成可读、可追溯的回答。
- 回答不得脱离提供的知识库上下文。

## 功能

- 调用检索模块取得证据。
- 构造回答上下文和引用约束。
- 调用生成模型并支持流式输出。

## 实现逻辑

- `generator.py` 接收问题和知识库参数。
- 通过混合检索获得片段后，按提示词模板组织上下文。
- 将模型输出转换为回答文本、来源和相关元数据。

## 代码范围

- `server/rag/generation/generator.py`
- `server/api/routes/chat.py`

## 依赖边界

- 依赖 `retrieval`、`prompts` 和 `core`。
- 不反向调用文档处理流水线。
