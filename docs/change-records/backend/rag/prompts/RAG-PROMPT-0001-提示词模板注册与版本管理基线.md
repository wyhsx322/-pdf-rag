# RAG-PROMPT-0001｜提示词模板、注册与版本管理基线

## 需求

- 集中保存 RAG 使用的提示词并支持版本化。
- 业务代码不得散落重复的提示词常量。

## 功能

- 保存回答生成、查询理解和 HyDE 模板。
- 按名称和版本注册、查询提示词。
- 支持评测不同提示词版本。

## 实现逻辑

- `templates.py` 保存回答生成通用模板。
- `registry.py` 建立提示词名称和版本映射。
- `v1/`、`v2/` 保存不同版本的查询理解、回答和 HyDE 实现。
- 评测模块通过注册表或明确版本加载提示词。

## 代码范围

- `server/rag/prompts/`
- `evaluations/eval_prompts.py`

## 依赖边界

- 不依赖其他 RAG 业务子域。
- 检索和生成模块可以单向依赖本模块。
