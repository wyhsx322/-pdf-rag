# EVAL-0001｜检索、提示词与写作轨迹评测体系基线

## 需求

- 使用可重复任务验证检索、提示词和写作工作流质量。
- 评测代码必须与生产代码分离。

## 功能

- 计算 Recall@K、MRR 和 NDCG。
- 对比不同提示词版本和是否使用 Reranker。
- 执行写作黄金任务并统计 Agent Trace、引用和用量。

## 实现逻辑

- `eval_retrieval.py` 执行检索任务并计算排序指标。
- `eval_prompts.py` 调用不同版本提示词，保存对比结果。
- `eval_trajectory.py` 创建临时写作任务，运行 Agent 并汇总轨迹指标。
- `golden/writing_tasks.json` 提供固定评测输入。

## 代码范围

- `evaluations/`
- `output/` 中的本地评测产物

## 依赖边界

- 可以依赖生产模块。
- `server` 和 `frontend` 禁止依赖 `evaluations`。
