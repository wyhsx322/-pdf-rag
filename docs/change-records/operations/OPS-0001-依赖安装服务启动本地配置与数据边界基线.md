# OPS-0001｜依赖安装、服务启动、本地配置与数据边界基线

## 需求

- 提供可复现的本地安装和启动方式。
- 确保密钥、PDF、数据库和生成产物不进入版本库。

## 功能

- 锁定 Python 和前端依赖。
- 一键或手动启动前后端。
- 管理环境变量模板和本地运行时配置。
- 规定运行数据、日志和构建产物的提交边界。
- 强制代码变更同步模块文档和纯标题索引。

## 实现逻辑

- `pyproject.toml` 与 `uv.lock` 管理 Python 环境。
- `frontend/package.json` 与锁文件管理前端环境。
- `start.ps1` 检查端口后启动 Uvicorn 和 Vite。
- `.env.example` 提供 Key 模板，`.gitignore` 排除本地敏感内容。
- `data/`、`primary_datas/` 和 `output/` 分别保存数据库、原始 PDF 和生成产物。
- 项目 `AGENTS.md` 强制触发用户级 `sync-project-change-docs` Skill，由 Skill 管理文档 ID、变更记录和索引同步流程。

## 代码范围

- `start.ps1`
- `pyproject.toml`
- `uv.lock`
- `frontend/package.json`
- `.env.example`
- `.gitignore`
- `AGENTS.md`
- `docs/change-records/`
- `data/`、`primary_datas/`、`output/`

## 依赖边界

- 公开仓库只保留模板和依赖声明。
- 任何真实密钥、用户 PDF、数据库、向量库和内部文档都不得提交。
